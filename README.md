# UniGrade — JNTUK Academic Calculator

UniGrade is a responsive student utility for calculating SGPA and CGPA. The current implementation includes JNTUK R23 support with an AI & DS I-I subject set, SGPA grade-point calculation, CGPA calculation, equivalent percentage, and student-friendly pages.

## Features

- SGPA calculator
- CGPA calculator
- JNTUK R23 / AI & DS support
- Equivalent percentage calculation
- Responsive layout
- Home, About and Contact pages
- GitHub Pages friendly static architecture

## Run locally

Open `index.html` in a browser, or serve the repository with any static web server.
